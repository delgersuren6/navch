# Sonor 🎙️

Real-time Mongolian lecture speech-to-text application.

## About

Sonor converts spoken Mongolian into text in real time, helping students capture and review lecture content.

## Features

- Real-time Mongolian speech recognition
- Live transcript display
- Save lectures to MySQL
- Lecture history
- Search saved lectures
- Export transcript as `.txt`

## Tech Stack

- HTML / CSS / JavaScript
- Web Speech API
- Node.js
- Express.js
- MySQL / MariaDB
